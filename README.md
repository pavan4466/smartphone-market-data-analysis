# Smartphone Market Data Analysis

## 📌 Project Overview
Analyzed Flipkart smartphone data to uncover pricing patterns, customer preferences, and brand competition.

## 🛠️ Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- BeautifulSoup

## 📊 Key Insights
- Mid-range segment dominates
- RAM + Storage strongly affect price
- Discounts do not significantly impact ratings
